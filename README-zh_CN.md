## 🚀 快速开始

### 5分钟设置

1. **获取API密钥**
   - 访问 [Google AI Studio](https://ai.google.dev/)
   - 免费注册并获取Gemini API密钥

2. **安装插件**
   ```bash
   # 方法1：通过WordPress后台
   WordPress后台 → 插件 → 安装插件 → 上传ZIP

   # 方法2：手动上传
   解压缩到 /wp-content/plugins/
   ```

3. **配置插件**
   - 进入 **WordPress后台 → AI 内容**
   - 点击 **API配置** 标签
   - 粘贴您的Gemini API密钥
   - 点击 **测试连接**（应该看到绿色勾）

4. **设置主题**
   - 点击 **基本设置** 标签
   - 填写您的主题和偏好设置

5. **测试生成**
   - 点击 **立即生成1篇**
   - 等待几秒钟
   - 完成！检查您的文章

6. **启用自动化**
   - 插件现在将每天自动生成文章！

## 🔧 功能详解

### 基本设置

#### 主题配置
```
主要主题: 您的核心主题（例如："科技新闻"）
主题描述: 详细描述您的内容焦点
子主题/关键词: 逗号分隔的相关主题列表
```

#### 内容设置
- **写作风格**: 专业、休闲、正式、对话式
- **目标读者**: 描述您的受众
- **每日文章数**: 1-20篇
- **字数**: 500-3000字
- **生成时间**: 选择每日生成时间（例如：凌晨2:00）

#### 发布设置
- **发布模式**: 立即发布或保存为草稿
- **发布间隔**: 文章之间的时间间隔（分钟）
- **默认分类**: 选择WordPress分类
- **自动生成标签**: 启用自动标签生成
- **SEO优化**: 启用SEO元数据

---

### API配置

#### API选择
选择要使用的AI API（Gemini、DeepSeek或OpenAI）

#### 高级选项
- **启用API轮换**: 在多个API之间轮换请求
- **API优先级**: 设置API使用顺序
- **失败时自动切换**: API失败时自动切换到备用API

#### API特定设置
每个API都有自己的配置：
- **API密钥**: 您的API密钥
- **模型**: 选择要使用的AI模型
- **温度**: 0.1-1.0（较低=更确定性，较高=更有创意）
- **最大令牌数**: 限制生成长度

## 📦 安装指南

### 方法1：通过WordPress后台（推荐）

1. 登录WordPress后台
2. 进入 **插件 → 安装插件**
3. 点击 **上传插件**
4. 选择 `ai-auto-content-generator.zip`

1. 下载插件ZIP文件
2. 解压缩文件
3. 通过FTP上传 `ai-auto-content-generator` 文件夹到 `/wp-content/plugins/`
4. 在WordPress后台激活插件

### 方法3：通过WP-CLI

```bash
wp plugin install ai-auto-content-generator.zip --activate
```

## ❓ 常见问题

### 一般问题

**Q: 我需要所有三个API密钥吗？**
A: 不需要！您只需要一个API密钥即可开始。我们推荐从Google Gemini开始，因为它有慷慨的免费额度且易于设置。

**Q: 费用是多少？**
A: 插件本身是免费的。您只需支付AI API的使用费用。使用Gemini的免费额度，您可以每天免费生成数十篇文章。DeepSeek极其实惠，300篇文章约$0.16/月。

**Q: 内容会是唯一的吗？**
A: 是的！插件包含高级防重复机制：
- 标题相似度检查
- 历史标题数据库
- 轮换写作角度
- 动态关键词混合

但是，我们始终建议在发布前审阅和编辑AI生成的内容。

**Q: 我可以自定义写作风格吗？**
A: 当然！您可以完全控制：
- 系统提示词（AI个性）
- 用户提示词模板
- 写作角度
- 字数
- 目标读者
- 主题焦点

**Q: 如果我的API配额用完了怎么办？**
A: 插件包含自动API故障转移。如果一个API失败或达到速率限制，它会自动切换到您的备用API。您还可以启用API轮换来分散负载。

**Q: 这会与我的主题一起使用吗？**
A: 是的！插件创建标准的WordPress文章，与任何主题兼容。它支持：
- 分类
- 标签
- 特色图片（如果设置）
- 自定义文章状态（草稿/已发布）

**Q: 使用安全吗？**
A: 是的！插件遵循WordPress编码标准并包含：
- Nonce验证
- 权限检查
- 输入清理
- 输出转义
- 安全的API密钥存储
- SQL注入防护
- XSS和CSRF防护

**Q: 我可以为不同时间安排文章吗？**
A: 是的！您可以：
- 设置每日生成时间（例如：凌晨2:00）
- 配置文章之间的发布间隔
- 设置发布模式（立即或草稿以供审阅）

**Q: 如何获得支持？**
A:
- 查看[文档](https://github.com/yourusername/ai-auto-content-generator)
- 在[GitHub上提出问题](https://github.com/yourusername/ai-auto-content-generator/issues)
- 查看[常见问题解答](https://github.com/yourusername/ai-auto-content-generator#faq)

### 技术问题

**Q: 最低系统要求是什么？**
A:
- WordPress 5.0或更高
- PHP 7.4或更高
- MySQL 5.6或更高
- 64MB+ 内存

**Q: 插件会影响网站性能吗？**
A: 不会。内容生成在后台通过WordPress Cron运行。它不会影响您网站的前端性能。

**Q: 我可以在多个网站上使用它吗？**
A: 是的！该插件是GPL许可的，您可以在任意数量的网站上使用它。

**Q: 数据存储在哪里？**
A:
- API密钥：WordPress options表（本地存储）
- 生成历史：自定义数据库表
- 日志：WordPress options（最近100条）
- 设置：WordPress options

**Q: 卸载时会发生什么？**
A: 插件包含适当的卸载处理器：
- 删除自定义数据库表
- 删除所有插件选项
- 清除定时任务
- 保留已生成的WordPress文章
